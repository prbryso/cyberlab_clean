Educational Registry Foundation

ADR-0001
Title: Educational content shall be registered rather than hardcoded.
Status
Accepted
Context
The original Cyber Lab implementation directly created module cards and navigation structures.
This tightly coupled educational content to the presentation layer.
Decision
Educational domains register their modules with the Educational Registry.
The engine discovers registered content.
The UI consumes registry data.
Consequences
Positive
Unlimited educational domains
Data-driven UI
Easier testing
Lower coupling
Simpler expansion
Negative
Additional abstraction
Slightly more startup initialization
Registry maintenance
Result
Systems Studio becomes an educational platform rather than a cybersecurity application.
