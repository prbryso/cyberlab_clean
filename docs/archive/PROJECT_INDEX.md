# Systems Studio Archive

> **Teach the System, Not Just the Rule**

---

## Purpose

The Systems Studio Archive preserves the complete history of the Systems Studio project.

It documents not only the software that was built, but also the engineering decisions, educational philosophy, architectural evolution, and lessons learned throughout the project's development.

The archive serves as the definitive historical record of the project and is the source from which the manuscript, presentations, white papers, and technical documentation are derived.
